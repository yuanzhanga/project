## 通用背调提醒

1. 量化指标（性能提升 X%、支撑 X 并发）没有压测/监控数据就不要写。
2. 「主导」「从 0 到 1」「独立负责」只有在 Git 证据强支撑时才可使用。
3. 他人主要贡献的模块，最多写「参与」或「协助」。
4. 项目性质（上线 / 课程 / 练习）如实呈现，背调或追问极易暴露。
5. 面试时所有表述都应能落到具体 commit 与文件，这是最硬的证据。
